# Scribble (Rabby)

Fast handwriting for pen tablets in Obsidian: full handwriting pages, and handwritten sections inside your notes.

## Features

- **Handwritten sections in notes**: type `/` and choose *Add new handwritten section* or *Add existing handwritten section*. You can write in them in Live Preview; Reading view only shows the ink.
- **Stays fast on long pages**: ink is drawn into tiles, so each new stroke costs the same however much is already on the page.
- **Pens**: fountain pen, ballpoint, pencil and highlighter, each with its own colour and size. You can adjust how each pen looks in the settings (thickness, pressure, smoothing, opacity, nib angle).
- **Eraser**: partial (erases only what it touches) or whole stroke.
- **Selection tool**: draw a loop around ink (or tap a stroke) to move, copy, cut, recolour or delete it. Tap an empty spot to paste, also into another section or page. Everything can be undone.
- **Palm rejection**: your palm doesn't draw, scroll the note or open the side drawers while you write.
- **Backgrounds**: ruled, grid, dots or blank (shown only while editing).
- **One floating toolbar**, shown only while a section is in focus.
- **Finger drawing** can be switched on; then two fingers scroll.

Handwriting is saved as `.scribble` files (JSON) in the `Scribble` folder.

## Install with BRAT

1. Install the **BRAT** community plugin.
2. Run **BRAT: Add a beta plugin for testing** and enter `rabby0101/obsidian-scribble`.
3. Enable **Scribble (Rabby)** under Community plugins.
